隱私權政策

ERP Hermes 行政助理 · 最後更新：2026-11-13

本隱私權政策說明 ERP Hermes 行政助理（以下稱「本應用程式」）如何存取、 使用與保護你的 Google 帳戶資料。本應用程式是帳戶持有人自行架設與 操作的私人工具，不對外提供服務。

1. 存取的資料

在你明確授權後，本應用程式可能存取：

  • Gmail — 郵件內容與標頭、標籤、寄送
  • Google Calendar — 日曆清單與活動內容
  • Google Drive — 檔案名稱、內容與中繼資料
  • Google Sheets — 儲存格內容
  • Google Docs — 文件內容
  • Google Contacts — 姓名與電子郵件（唯讀）

2. 資料如何被使用

所有資料僅用於執行帳戶持有人要求的任務。本應用程式 不會將你的資料用於廣告、行銷、剖析，也不會用於訓練或改良任何人工智慧 或機器學習模型。

3. 分享與揭露

我們不會販售、出租或提供你的 Google 使用者資料給任何 第三方。資料僅在提供你所要求的功能所必需時才會被處理，或於法律要求時 揭露。

Google API 服務使用者資料政策（有限使用）：
本應用程式對從 Google API 取得的資訊之使用，將遵循 Google API 服務使用者資料政策， 包括其「有限使用」要求。

4. 儲存與安全

存取憑證（OAuth token）僅儲存在帳戶持有人自己的本機裝置上。衍生資料 （如報表、會議紀錄、信件草稿）保存在帳戶持有人的本機檔案系統及/或 其本人的 Google Drive 中。本應用程式不架設集中式伺服器來儲存 Google 資料。

5. 保存與刪除

你可以隨時到 myaccount.google.com/permissions 撤銷本應用程式的存取權。撤銷後，本應用程式即無法再存取你的 Google 資料，且本機儲存的存取 token 會被刪除。若要刪除其他衍生資料，請使用 下方聯絡方式提出。

6. 政策變更

重大變更會公布在本頁面，並反映於上方的「最後更新」日期。
